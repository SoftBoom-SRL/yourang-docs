# Create the Meta agent

Create the agent that will reply to messages and comments, choosing the right type and its first settings.

_With your accounts connected, you create the agent itself. The flow is guided and takes a few minutes: pick the “Meta” type, give it a name and decide how to treat comments._

## Open the agent creation flow <a id="apri-agenti"></a>

1. **Go to “AI Agents”** — In Yourang's left-hand menu click the AI agents section.
2. **Press “Create agent”** — The button is at the top right of the agent list. A guided multi-step window opens.

## If the “Meta” card is disabled <a id="prerequisiti-creazione"></a>

In the type-selection screen the “Meta” card stays greyed out and unclickable until the Meta integration is connected: a note under the card invites you to link Instagram and Facebook first. A Meta agent with no connected accounts would have nothing to reply to. Complete the connection (see “Connect Instagram and Facebook”), reload the page, and the card becomes selectable.

> [!NOTE]
> **A Plus or Enterprise plan is required**
> Even with the accounts connected, the Meta agent only works on a Plus or Enterprise plan. On another plan you may be able to create the agent, but the interaction counter will show a padlock and the agent will not reply. See “Plans, interactions and limits”.

## The creation steps <a id="passaggi"></a>

1. **Choose the “Meta” type** — In the first screen (“Choose the agent type”) you see three cards: Inbound, Outbound and Meta. Click the “Meta” card — the one described as “Replies to Instagram and Facebook DMs and moderates comments”. The selected card is highlighted.
2. **Press “Continue”** — You move on to the details screen.
3. **Name the agent** — The “Agent name” field is pre-filled with an editable default. Write a recognisable name, for example “Reception” or “Social assistant”. It must be at least 2 characters long.
4. **Decide whether to hide abusive comments** — You'll find the “Automatically hide abusive comments” switch (see below). It is on by default: leave it that way if you want the agent to hide spam and insults.
5. **Press “Create agent”** — The agent is created and its configuration page opens, where you complete the settings (see “Configure the agent”).

## The “Hide abusive comments” option <a id="nascondi-abusivi"></a>

When it is on, the agent automatically hides clearly offensive or spammy comments instead of replying. Important: genuine questions and legitimate criticism are NEVER hidden — they always get an answer. The goal is to protect your profile's image, not to silence people with something to say. You can change this later from the agent's “Comments” tab, and refine it with rules you write yourself.

## Right after creation <a id="dopo-la-creazione"></a>

> [!WARNING]
> **The agent is not live yet**
> Once created, the agent exists but doesn't reply yet: you first complete the configuration (instructions, reply mode) and then switch it on with the toggle at the top of the page. It's all in “Configure the agent”.

> [!NOTE]
> **The type can't be changed later**
> A Meta agent stays a Meta agent: the type is chosen at creation and cannot be turned into a voice agent (on the agent page the “Agent type” dropdown stays locked). If you need a different type, create a new agent.

> [!TIP]
> **One active Meta agent at a time**
> Incoming messages and comments are handed to your business's active Meta agent. If you create more than one, keep only the one you want to use active: leave the others switched off as drafts.
